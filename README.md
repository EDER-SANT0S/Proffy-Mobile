# Proffy Mobile

Aplicativo Android desenvolvido em Kotlin com layouts XML no Android Studio.

## Funcionalidades

- Tela de abertura.
- Tela de entrada com campos de e-mail e credencial.
- Entrada de e-mail configurada para endereços eletrônicos.
- Campo de credencial com caracteres ocultos.
- Botão Entrar para demonstrar a leitura dos campos.

## Tecnologias

- Kotlin
- Android SDK
- XML para layouts
- View Binding
- AndroidX
- Material Components

## Como executar

1. Abra o projeto no Android Studio.
2. Aguarde a sincronização do Gradle.
3. Selecione um emulador ou conecte um dispositivo Android.
4. Execute a configuração app.
